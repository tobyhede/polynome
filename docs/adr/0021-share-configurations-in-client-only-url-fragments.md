# Share Configurations in client-only URL fragments

Polynome shares the current Configuration as a self-contained URL fragment. A
Share link is not a Preset: it carries no name, does not enter the recipient's
saved Presets, and opens as an unnamed current Configuration that the existing
`+ Save` flow can name. It carries everything in the Configuration and nothing
outside it, so Accent, transport state and transient interface state do not
travel. Generated Cycle and Rhythm-layer identifiers are omitted because they
have no musical identity and are regenerated by Configuration repair.

The fragment is `#share=<payload>`, where the payload is the ordinary
local-storage Configuration JSON compressed with the browser's native gzip
streams and encoded as URL-safe Base64. A fragment keeps the Configuration out
of the server request, gzip keeps the bounded but verbose JSON reliable through
share targets, and reusing the storage shape leaves `configuration.ts` as the
one authority for the data. Polynome adds no backend, dependency, compact wire
schema, name wrapper, format version or uncompressed fallback. Browsers without
the required compression streams do not show the Share control.

Opening a recognizable Share link takes precedence over the current
Configuration restored from local storage, repairs through the ordinary
Configuration boundary, starts stopped, and immediately writes that unnamed
Configuration as the current workspace without changing saved Presets. Only a
successful write consumes the fragment with `history.replaceState`; when
storage refuses, the Configuration remains usable in memory and the fragment
remains available to recover it on refresh. Broken compression, unparseable
JSON and values without the Configuration's core structure leave the local
workspace untouched and report a visible failure. Decompression stops and
rejects beyond 64 KiB so an untrusted fragment cannot expand without bound.

The top-menu Share control invokes the native share sheet with the title
`Polynome` and the URL alone, falling back to clipboard when native sharing is
absent or fails. Cancelling a native share is silent. The control shares the
declared Configuration without stopping or restarting a Transport run; a live
tempo inside a Cycle BPM envelope is not substituted for the Configuration's
Starting BPM.

Share links have the same pre-release compatibility policy as stored
Configurations: recognizable older shapes may be repaired, but there is no
migration or compatibility shim. Once Polynome is released, changing the
Configuration shape requires deciding the durability promised to links already
in circulation as well as data already in browser storage.
